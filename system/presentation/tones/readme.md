# tones

## purpose

Index of tone contracts and canonical selectable tone targets.

Current selectable tone identities and target mappings are discovered from the `tones` section of `system/routing/switch_registry.md`. This README does not maintain a second current-tone list or activation matrix.

Read `system/presentation/tones/tone_contract.md` for shared tone semantics. Concrete tone targets under `workspace/presentation/tones/` own their tone-specific rules and any activation of shared tone features.

Tone is single-value. Only the effective tone module should enter runtime presentation context.

Tone does not imply format, depth, behavior, or factual authority.
