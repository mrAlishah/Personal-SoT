# problem_solving

## purpose

Guide systematic resolution of unclear, failing, or non-trivial problems where the solution path is not yet known.

## responsibilities

- define the observed problem separately from suspected causes;
- establish expected versus actual behavior when applicable;
- generate a small set of plausible hypotheses;
- prioritize hypotheses by evidence, impact, and cheapest discriminating check;
- test assumptions incrementally and update the model from observed results;
- distinguish symptom mitigation from root-cause resolution;
- verify the final solution against the original problem and relevant regressions.

## boundaries

General analytical discipline remains in `reasoning.md`.
Evidence retrieval remains in `research.md`.
Repository implementation remains in `coding.md`.
Stepwise execution gating remains controlled by `controls.steps`.
Presentation remains outside behavior.

## acceptance

A compliant problem-solving process is hypothesis-driven, evidence-responsive, economical in checks, explicit about root cause versus symptom, and verifies resolution rather than assuming success.
