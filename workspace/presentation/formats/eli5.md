# eli5

## purpose

Render explanations in accessible plain language without sacrificing correctness.

## rules

- prefer concrete everyday wording over unnecessary jargon;
- define unavoidable technical terms briefly;
- make the central idea easy to identify;
- use a simple analogy or example only when it materially improves comprehension;
- preserve important caveats instead of making a false simplification;
- do not silently increase response depth or activate teaching behavior.

This is a rendering convention. Concept sequencing and pedagogy remain owned by `behavior/teaching.md`.
