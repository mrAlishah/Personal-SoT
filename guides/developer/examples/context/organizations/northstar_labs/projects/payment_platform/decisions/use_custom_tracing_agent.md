# use_custom_tracing_agent

> FICTIONAL DECISION EXAMPLE ONLY.

## decision

Use a custom tracing agent for payment-service telemetry. <!-- HISTORICAL FAKE EXAMPLE -->

## context

At the time, required tracing features were not available in the standard observability stack.

## consequences

The custom agent created maintenance overhead and proprietary instrumentation coupling.

## supersession

The project now uses OpenTelemetry as current stack truth. This deprecated decision remains only for historical understanding and should not guide new work.
